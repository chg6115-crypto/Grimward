## 1. 구조 규칙 (M1 규칙 + 추가)

- M1 지시서 2장(어셈블리 분리, 인터페이스 제한, 금지 사항)을 그대로 지킨다.
- 새 Domain 폴더:

```
Domain/
  Characters/   CharacterStats, Adventurer, StatFormulas, ...
  Combat/       CombatFormulas, Combatant, BattleState, TurnOrder, BattleResult, EnemyFactory, ...
```

- **전투 계산(명중·피해·턴 순서)은 Combat 폴더에만** 둔다. `ExplorationState`에 전투 공식을 넣지 않는다.
- `ExplorationState`가 커지지 않게 한다. 전투 시작·종료를 연결하는 역할만 하고, 전투 진행은 `BattleState`(또는 같은 역할의 클래스)가 담당한다.
- 새 인터페이스는 만들지 않는다. 단 **`IRandomSource`에 정수 난수 메서드를 추가**한다 (예: `int NextInt(int minInclusive, int maxInclusive)`). 테스트용 가짜 난수도 함께 갱신한다.
- 공식은 상태 없는 순수 함수로 만들어도 된다 (예: `CombatFormulas.HitChance(...)`). 수치는 반드시 `BalanceConfig`에서 받는다.
- UI는 **M1과 같은 방식(코드 생성, UiFactory)** 을 유지한다. 프리팹 전환은 그래픽 단계에서 따로 한다.

## 2. 캐릭터와 몬스터 데이터 (Part I 5장, 7장)

### 2-1. 검사 (Lv1, v0.1 고정)

| 능력치 | 값 |
|---|---|
| 근력 / 민첩 / 건강 / 지능 / 지각 / 매력 | 5 / 3 / 4 / 1 / 3 / 3 |
| 무기 (연습용 검) | 피해 4~8 |
| 방어구 (가죽 갑옷) | 상시 방어도 5% |
| 레벨 | 1 |

**파생 수치 공식** (`StatFormulas`, 계수는 `BalanceConfig`)

| 수치 | 공식 | Lv1 검사 |
|---|---|---|
| 최대 HP | 20 + 건강 × 3 | 32 |
| 공격력 | 무기 피해 + 근력 ÷ 2 (버림) | 6~10 |
| 명중 | 민첩 × 2 + 레벨 × 2 | 8 |
| 회피 | 민첩 × 3 + 지각 ÷ 2 (버림) | 10 |
| 치명타 확률 | 3% + 민첩 × 0.5% | 4.5% |
| 속도 | 민첩 + (근력 + 지능 + 건강) ÷ 3 (버림) | 6 |

- 레벨업 처리는 M4. M2는 Lv1 고정이지만 **레벨을 입력받는 공식**으로 만든다.
- 모험가의 현재 HP는 출정 중 유지된다 (전투가 끝나도 회복되지 않음).

### 2-2. 고블린

| 항목 | 값 |
|---|---|
| 무리 | 2~3마리 (전투마다 랜덤) |
| HP | 10 |
| 공격력 | 2~4 |
| 명중 / 회피 / 속도 | 10 / 10 / 4 |
| 상시 방어도 | 0% |

- 고블린 수치는 **직접 지정값**으로 둔다 (`BalanceConfig`의 몬스터 항목). 능력치로 다시 계산하지 않는다.
- 노드 전투와 경로 매복 모두 고블린 무리.

## 3. 전투 규칙 (Part I 10장)

### 3-1. 진행

- 라운드마다 살아 있는 모든 전투원이 행동 1회.
- 라운드 시작 시 각자 **우선도 = 속도 + 1d8** (1~8 정수)을 굴려 높은 순서로 행동.
- 동률: 기본 속도가 높은 쪽 → 그것도 같으면 무작위.
- 라운드 도중 쓰러진 전투원은 남은 차례를 건너뛴다.

### 3-2. 모험가 행동

| 행동 | 효과 |
|---|---|
| 공격 | 살아 있는 고블린 1마리를 선택해 공격 |
| 방어 | **다음 자기 턴이 시작될 때까지** 피해 감소에 +30% + 검사 직업 보너스 5%p |
| 도주 | 3-5 |

- 회복약 사용은 M3에서 추가한다. 행동 목록을 나중에 늘리기 쉬운 구조로 만든다.

### 3-3. 적 행동

- 고블린은 항상 모험가를 공격한다.

### 3-4. 명중과 피해 (순서 엄수)

1. **명중률** = Clamp(85% + (공격자 명중 − 방어자 회피)%p + 밤 보정, 5%, 95%)
   - 밤 보정: 모험가가 공격할 때 −10%p, 적이 공격할 때 +10%p.
   - 밤 여부는 **전투 시작 시각**으로 정하고 전투 중 바꾸지 않는다.
2. 명중하면 **치명타 판정**. 성공 시 굴린 피해 × 1.5.
3. **피해 감소율** = 상시 방어도 + (방어 중이면 30% + 직업 보너스 5%). 타이밍 방어는 0.
4. **최종 피해** = 피해 × (1 − 피해 감소율) → **소수점 버림**.
   - 최소 피해 보정은 하지 않는다 (0이 될 수 있음).
- 예: Lv1 검사(명중 8) → 고블린(회피 10), 낮 명중률 83%, 밤 73%. 고블린 피해 3 → 검사(방어도 5%) 2.

### 3-5. 도주

- 행동 1회, **반드시 성공**.
- 모험가는 최대 HP의 20% 피해를 받는다. 단 **HP 1 아래로 내려가지 않는다.**
  - 피해 반올림 방식은 **[미정]** → `BalanceConfig`에 옵션으로 두고 기본값은 **버림** (32 × 20% = 6.4 → 6). 보고서에 적는다.
- 전리품 없음.
- **이미 처치한 고블린 수는 전투 결과에 남긴다** (M4에서 의뢰 진행도에 반영).

### 3-6. 승리·패배

- 고블린 전멸 → 승리.
  - **드랍 결정**: 마정석(하) 1~2개, 20% 확률로 마정석(중) 1개. M2는 `BattleResult`에 드랍 목록을 담고 로그로만 출력한다 (가방은 M3).
- 모험가 HP 0 → **사망**.
  - 탐험 상태를 "사망"으로 바꾸고 이동·귀환·행동 버튼을 모두 비활성화한다.
  - 로그: "사망 — M4에서 처리". 테스트용으로 화면에 **다시 시작** 버튼(같은 씬 재시작)을 둬도 된다.

### 3-7. 전투 결과 (`BattleResult`)

- 결과 종류(승리 / 도주 / 사망), 처치한 고블린 수, 드랍 목록, 전투 종류(노드 / 매복).

## 4. 탐험과 연결 (Part I 9장)

### 4-1. 노드 전투

- **완료되지 않은 전투 노드에 도착하면 전투가 시작**된다. 이동 시간은 먼저 적용된다.
- 승리 → 노드 **이벤트 완료**, 전투 시간 30분.
- 도주 → 노드는 **미완료로 남고**, 모험가는 **직전 노드로 후퇴**한다. 시간은 3-8.
- 도주한 노드에 다시 들어가면 새 고블린 무리와 다시 전투한다.

### 4-2. 경로 매복 (M1의 "매복 발생 — M2에서 구현" 대체)

- 경로 이벤트가 발생하면 **목적지에 도착하기 전에** 매복 전투가 시작된다.
- 승리 → 목적지에 도착, 경로는 통과로 기록, 목적지 노드 처리(빈 노드 완료, 전투 노드면 노드 전투 시작 등)는 M1과 같다.
- 도주 → **출발 노드로 돌아가고 경로는 통과로 기록하지 않는다.**
- 자동 귀환 중 매복이 나면 귀환을 멈춘다. 승리하면 남은 귀환 경로를 이어서 간다. 도주하면 자동 귀환을 취소한다.

### 4-3. 전투 관련 시간

| 상황 | 시간 | 상태 |
|---|---|---|
| 일반 전투 | 30분 (라운드 수와 무관) | 확정 |
| 도주 | 60분 | 확정 |
| 도주 시 전투 30분과 합산 | **[미정]** → 기본값: 합산하지 않고 60분만 | 옵션 |
| 매복 후 승리 | 이동 시간 전체 + 전투 30분 | [미정] → 기본값 |
| 매복 후 도주 | 이동 시간 전체 + 도주 시간 | [미정] → 기본값 |

- [미정] 항목은 `BalanceConfig` 옵션으로 두고 보고서에 적는다.

## 6. 화면 (최소)

- 전투가 시작되면 탐험 화면 위에 **전투 패널**(`Panel_Battle`)을 띄운다.
  - 모험가 HP (`Txt_PlayerHp`), 고블린 목록과 HP (`Btn_Target_00`, `Btn_Target_01`…: 누르면 공격 대상 선택)
  - 행동 버튼: `Btn_Attack`, `Btn_Defend`, `Btn_Flee`
  - 이번 라운드 행동 순서와 결과를 전투 로그(`Panel_BattleLog`)에 출력: 명중률, 명중/빗나감, 치명타, 피해, 방어 여부.
- 전투 중에는 탐험 버튼(이동·귀환)을 비활성화한다.
- 탐험 화면 상단에 모험가 HP를 항상 표시한다 (`Txt_Hp`).
- 사망하면 `Panel_Death`를 띄운다.

## 7. 테스트 (EditMode, Domain만)

기존 28개를 유지하고 아래를 추가한다. 난수는 테스트용 고정 값을 주입한다.

1. StatFormulas: Lv1 검사 HP 32, 공격력 6~10, 명중 8, 회피 10, 치명타 4.5%, 속도 6. 고블린 속도 4.
2. 명중률: 낮 83%, 밤 모험가 73%·고블린 95%(상한), 하한 5%·상한 95% 클램프.
3. 피해 계산 순서: 치명타 ×1.5 → 감소율 적용 → 버림. 예: 피해 3, 방어도 5% → 2. 방어 중(5+30+5=40%) 피해 10 → 6.
4. 방어 지속: 방어한 뒤 다음 자기 턴이 시작되면 효과가 사라진다.
5. 턴 순서: 속도 + 1d8 내림차순, 동률 시 기본 속도 우선, 쓰러진 전투원 건너뛰기.
6. 도주: 최대 HP 32 → 피해 6, HP 3일 때 도주하면 1, HP 1이면 1 유지. 처치 수는 결과에 남음.
7. 노드 전투: 승리 시 노드 완료 + 30분, 도주 시 노드 미완료 + 직전 노드로 후퇴 + 60분.
8. 매복: 승리 시 목적지 도착·경로 통과 기록, 도주 시 출발 노드 복귀·경로 미통과·이동 시간 + 도주 시간.
9. 자동 귀환 중 매복: 승리하면 귀환 재개, 도주하면 귀환 취소.
10. 사망: HP 0이면 탐험 상태가 사망으로 바뀌고 이동·귀환이 거부된다.
11. 드랍: 고정 난수에서 마정석(하) 개수와 마정석(중) 여부가 기대대로 나온다.
12. 결정성: 같은 시드와 같은 행동 순서로 전투를 두 번 돌리면 결과(로그·HP·드랍)가 같다.

## 8. 완료 조건 (M2)

- Main 씬에서 전투 노드에 들어가면 전투가 시작되고, 공격·방어·도주로 끝까지 진행된다.
- 경로 매복이 발생하면 매복 전투가 진행되고, 결과에 따라 목적지 도착 또는 출발 노드 복귀가 된다.
- 전투 노드를 이긴 뒤에는 그 노드를 지나 자동 귀환할 수 있다 (M1의 "전투 노드 뒤로 귀환 불가"가 풀린다).
- 사망하면 탐험이 멈춘다.
- 모든 EditMode 테스트가 통과한다. Domain에 UnityEngine 참조가 없다.

## 9. 정리 작업 (선택, 시간이 되면)

- `FogOfWar.RevealFrom`이 노드의 `IsVisited`까지 바꾸고 있다. 방문 처리는 이동 쪽으로 옮겨 안개는 "발견"만 담당하게 한다.
- 카메라·부트스트랩·EventSystem 오브젝트 이름의 `Panel_` 접두어는 UI 패널에만 쓰도록 정리한다 (예: `Main Camera`, `GameBootstrap`, `EventSystem`).
- 한 줄에 여러 문장이 있는 코드는 읽기 쉽게 줄을 나눈다.
