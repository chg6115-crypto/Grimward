## v0.1 마일스톤

순서: **전투 → 탐험 → 마을 → 콘텐츠 → 습격**. 각 마일스톤은 앞 단계를 실제로 쓸 수 있는 상태로 끝낸다.

### M0. 재시작 준비
- 이전 코드 git 태그 `archive/pre-restart`, `Assets/_Project` 정리, 새 asmdef 구성
- Core 재사용: HexCoord, GameTime, SeededRandom(IRandomSource)
- 데이터 틀: 직업·기술·몬스터 정의(ScriptableObject → Domain), BalanceConfig
- **완료 조건**: 빈 Title·Town·Expedition 씬이 열리고 EditMode 테스트(Core)가 통과

### M1. 전투 코어
- 4칸 진형, 1번부터 채움, 사망 시 당김, 위치 교환
- 행동 순서(속도 + 1d8), 기술 / 이동 / 넘기기 / 도주, 아이템(턴 소모 없음, 턴당 1개)
- 명중·치명·피해 공식, 밤 보정
- 기술 효과 조합: 피해·다중·버프·디버프·중독·회복·위치 이동·진형 붕괴·방어도 무시
- **v0.1 기술 20개** + 몬스터 기술(고블린·투석병·주술사·방패병·우두머리·악마)
- 적 AI(규칙 기반 단순 선택)
- 전투 화면(Panel_Battle): 진형 표시, 기술 버튼, 대상 선택, 로그
- **완료 조건**: 테스트 씬에서 2~4인 파티 vs 고블린 3~4마리·보스방 편성 전투를 끝까지 진행. 공식·상태 효과·진형 규칙 테스트 통과

### M2. 탐험
- MapData·노드·경로, IMapProvider: **튜토리얼 고정 맵**, **얕은 숲 구조 3종**(빼는 노드 0~3개), MapValidator
- 이벤트 배치(규칙 + 무작위), 노드 이벤트 겹침, 막다른 곳 규칙
- 이동·시간(60/30분), 전장의 안개, 밤 랜덤 전투, 도주 후퇴
- 조사 물건 7종(좋음·보통·나쁨, 보급품·직업·지각 보정), 보물
- 가방 12칸, 보급품 4종(회복약·약초·열쇠·횃불), 횃불 효과
- 수동 귀환·자동 귀환(킹덤 컴식 한 칸씩), 일부 사망·전멸 처리
- 지도 화면(육각 타일 재사용), 지도 위 파티 아이콘
- **완료 조건**: 얕은 숲 맵에서 이동·전투·조사·보물·귀환까지 한 번의 출정이 끝난다. 맵 검증·배치 규칙 테스트 통과

### M3. 마을과 루프
- 마을 메인(Panel 전환), 로스터, 날짜·습격 카운트다운·골드·의뢰 요약
- 길드: 의뢰 4종(같은 의뢰 1개, 기한·누적·보장), 고용(직업 5개, 특성 0~1/0~1, 고용비)
- 상점(보급품), 자택(휴식·장신구 슬롯 표시), 묘지(기록)
- 출정 준비 5단계, 귀환 정산(의뢰 보고·환금·경험치·레벨업), 전멸 결과
- 하루 1회 출정, 휴식 = 다음 날 06:00
- 로컬 자동 저장·불러오기, 강제 종료 시 출정 전 복원
- **완료 조건**: 마을 → 출정 → 귀환 → 정산 → 휴식이 여러 번 반복되고, 껐다 켜도 이어진다

### M4. 콘텐츠와 튜토리얼
- 튜토리얼 흐름(약초 3개, 진형 붕괴 없음, 조사 좋음 고정, 열쇠 지급, 20:00 악마), 튜토리얼 직후 고용 강제·첫 3명 무료
- 얕은 숲 일반 전투 편성(고블린 최소 2 + 투석병·주술사 3·4번), 보스방(보스 토벌 의뢰 시)
- 특성 16종 중 v0.1 대상(고용 시 부여, 수치 보정)
- 수치 1차 조정(임시값 점검)
- **완료 조건**: 새 게임부터 튜토리얼 → 고용 → 일반 출정 → 보스 토벌까지 플레이 가능

### M5. 주간 악마 습격
- 7일차 20:00 습격, 하루 전 알림, 출정 준비 경고, 출정 중 자동 귀환
- 방어전 준비(귀환 파티 + 대기 로스터 중 4명), 악마 1마리 전투
- 결과: 승리 「악마의 정수」 / 패배 골드 30%, 그다음 출정 정산
- **완료 조건**: 1주 차를 처음부터 끝까지 플레이하고 습격을 막거나 실패한 뒤 8일차로 넘어간다 → **v0.1 완성**

- 각 마일스톤은 `개발규칙` 12장 양식의 보고서와 함께 끝낸다.

- 작업지시서가 필요하면 마일스톤마다 `Grimward_작업지시서_M?.md`로 새로 쓴다(이전 M1~M3 지시서와 무관).
