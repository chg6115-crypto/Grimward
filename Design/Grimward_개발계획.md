## v0.1 마일스톤

순서: **전투 → 탐험 → 마을 → 콘텐츠 → 습격**. 각 마일스톤은 앞 단계를 실제로 쓸 수 있는 상태로 끝낸다.

### M0. 재시작 준비
- 이전 코드 git 태그 `archive/pre-restart`, `Assets/_Project` 정리, 새 asmdef 구성
- Core 재사용: HexCoord, GameTime, SeededRandom(IRandomSource)
- 데이터 틀: 직업·기술·몬스터 정의(ScriptableObject → Domain), BalanceConfig
- **완료 조건**: 빈 Title·Town·Expedition 씬이 열리고 EditMode 테스트(Core)가 통과

### M1. 전투 코어
- 4칸 진형, 1번부터 채움, 사망 시 당김, 위치 교환
- 행동 순서(속도 + 1d8), 기술 / 이동 / 넘기기 / 도주, 아이템(턴 소모 없음, 턴당 1개)
- 명중·치명·피해 공식, 밤 보정
- 기술 효과 조합: 피해·다중·버프·디버프(누적)·중독·회복·위치 이동·진형 붕괴·방어도 무시
- 피해 계산: % 계산 내림 통일, **명중 시 최소 피해 1**(구현 완료 11-11)
- **전투 연출(11-12)**: 행동 기록을 순서대로 재생(공격자 돌진 → 맞음 흔들림·회피·사망 흐려짐), 떠오르는 글자(피해·치명타·회피·회복·중독/출혈·효과·부상·저항), 연출 속도 ×1/×2. 기술별 이펙트는 아트 확정 후
- **부상 구현 완료(11-11)**: 부상 데이터(얕은/깊은 베임·뇌진탕), 태그 기술 확률·치명타 100%, HP 30% 악화, 최대 2종, 출혈(처음 3/4라운드), 현장 치료(응급처치·치유의 빛·붕대), 모험가에 저장, 휴식(뇌진탕)·치료소(전부) 회복 함수
- **상태이상·저항·전투불능 구현 완료(11-12)**: 확률 = 기술 확률 − 저항, 몬스터 저항(등급 10/20/40%)·면역 목록, 모험가 저항(건강·지능), 기절(차례 건너뜀 + 다음 차례까지 저항 +30%p), 출혈(급습·관통 사격)·화상(화염구), 마법 피해(마법 저항, 기본 0), 거구의 벽 → 아군 진형 붕괴 저항 +70%p 오라, 전투불능(승리·도주 시 HP 1 + 중상 1, 한 출정 두 번째면 사망, 전멸은 전원 사망). 상세 정보에 저항 표시
- **기술 피해 범위 구현 완료(11-12)**: 능력치 가중치(÷6) · 편차 3단계(정밀·보통·거침) · 지각 안정성(하한만), 회복 기술도 가중치 보너스, 매직 애로우 고정 피해 공식 정리, 기술 툴팁에 실제 피해 범위 표시
- **전투 UI 조작(11-12)**: 단축키 1~4 기술 · 5 이동(버튼 눌림 연출, 다시 누르면 취소), 자신·아군 전체 기술도 아군 칸을 눌러야 발동, 상세 정보 저항은 왼쪽 능력치 칸으로
- **보스 강화(11-12)**: 홉고블린·버그베어 HP 85 · 공격 6~10, 고블린 정예 HP 26 · 공격 6~8
- **출정 압박(전투 쪽)**: 부상(태그 기술 확률·치명타 100%·HP 30% 악화, 최대 2종, 출혈·명중 감소), 기절(검사 강타), 부상·허기를 전투 시작 때 패시브로 적용, 현장 치료(응급처치·치유의 빛·붕대, 회복약은 부상 치료 없음)

## 마일스톤 공통

- 각 마일스톤은 `개발규칙` 12장 양식의 보고서와 함께 끝낸다.
- 끝날 때마다 직접 플레이해서 기획 문제를 기록하고, 다음 마일스톤 전에 기획안·엑셀에 반영한다.
- 작업지시서가 필요하면 마일스톤마다 `Grimward_작업지시서_M?.md`로 새로 쓴다(이전 M1~M3 지시서와 무관).
